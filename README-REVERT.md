# Reversão necessária

O index.html foi acidentalmente simplificado.

## Como restaurar o código completo original:

1. Baixe o arquivo original:
   https://raw.githubusercontent.com/Renan-Misael/site-musica/0f5ab01a9314319b8210d5eb70aff24e20e43f72/index.html

2. Ou no terminal (se tiver o repo clonado):
```bash
git checkout 0f5ab01a9314319b8210d5eb70aff24e20e43f72 -- index.html
git add index.html
git commit -m "Restaura index.html original completo"
git push
```

O arquivo completo tem ~70KB e inclui: teoria/quiz, cursos, metrônomo, formulário de inscrição, biblioteca de partituras, etc.
