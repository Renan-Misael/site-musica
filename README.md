# Harmonia Academy

Site de educação musical (HTML + CSS + JS).

## Como abrir

Abra **index.html** no navegador, com os arquivos na mesma pasta:

- `index.html`
- `site.css`
- `app.js`

Ou ative **GitHub Pages** (Settings → Pages → branch `main`).

## Conteúdo

- Teoria musical (quizzes)
- Biblioteca de partituras com transposição e PDF
- Metrônomo
- Formulário de inscrição
