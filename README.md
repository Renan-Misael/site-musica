# Harmonia Academy

Site **100% estático** (HTML + CSS + JS).
**Não precisa de terminal, npm nem servidor.**

## Como usar

1. Abra `index.html` no navegador (duplo clique), **ou**
2. Ative GitHub Pages no repositório (Settings → Pages → branch `main`).

## Arquivos principais

| Arquivo | Função |
|---------|--------|
| `index.html` | Site público |
| `site.css` | Estilos do site |
| `app-part1.js` + `app-part2.js` | Teoria, partituras, metrônomo, inscrição |
| `login.html` | Login admin |
| `inscricoes.html` | Painel de inscrições |
| `style.css` | Estilos das páginas admin |
