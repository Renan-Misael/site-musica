# Harmonia Academy

Site **100% estático** — sem terminal, sem npm, sem servidor.

## Abrir o site

1. Baixe os arquivos do repositório (ou o ZIP completo).
2. Abra **`index-completo.html`** no navegador (recomendado — 1 arquivo só).
   Ou abra `index.html` com `site.css` e `app.js` na mesma pasta.
